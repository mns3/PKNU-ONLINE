## 🎮 프로젝트 소개

**PKNU-ONLINE** 은 실제 부경대학교 캠퍼스를 1:1 스케일로 재현한 디지털 트윈 콘텐츠입니다.

캠퍼스 규모의 공간을 2명에서 6개월 안에 작업을 해야 했기에, AI를 활용하여 **결과물을 만들어 내는 파이프라인을 먼저 만드는 방향** 으로 접근했습니다. GIS 데이터로 정확한 스케일의 기반 형상을 확보하고, 현장 사진을 입력으로 생성형 AI가 텍스처와 모델을 채우고, 반복 오브젝트는 PCG 알고리즘이 배치하는 구조입니다.

## ⚙️ 기술 구현 상세

### 1. GIS 데이터로 스케일 기준을 먼저 확보

넓은 캠퍼스를 하나하나 수작업으로 스케일을 확인하기엔 시간이 부족하여 기존에 있는 GIS 데이터를 활용하기로 결정하였습니다.

V-World에서 취득한 **건물 도면(LoD0)** 과 **건물 높이 DB** 를 결합해 화이트박스용 블록 모델을 생성했습니다. 이후 AI가 만드는 텍스처를 그 위에 얹히는 방식으로 중요도가 낮은 건물을 제작하였습니다.

![LoD0 도면 데이터](Lod0.png)
![LoD1 블록 모델](Lod1.png)

### 2. TaxutreMaker — 사진 1장에서 PBR 텍스처 5종을 생성하는 웹 툴

현장에서 찍은 사진을 나노바나나를 통해 그림자 제거, 보정을 한 이후 텍스처 맵 변환 작업을 위해 직접 만든 도구입니다. 저장소의 [`TaxutreMaker.html`](TaxutreMaker.html) 파일 하나로 동작하며, 설치 없이 브라우저에서 실행됩니다.

![TaxutreMaker 실행 화면](test1.png)

**생성하는 맵**

| 맵 | 생성 방식 |
| :--- | :--- |
| Normal | 픽셀 휘도(ITU-R BT.601 가중치)의 기울기를 구해 기울기 벡터를 탄젠트 공간 노멀 값으로 인코딩 |
| Roughness | 휘도 반전 및 대비 조정 |
| Ambient Occlusion | 휘도 기반 음영 강조 |
| Displacement | 휘도를 높이값으로 매핑 |
| Emissive | 빛나는 부분을 사용자가 브러시로 직접 영역을 정하여 생성 |

**구현 포인트**

- **Emissive 마스크 에디터** — 원본과 마스크를 2개 레이어 캔버스로 겹치고, `globalCompositeOperation` 합성 모드로 브러시와 지우개를 구현했습니다. 캔버스의 내부 해상도와 화면 표시 크기가 다르기 때문에, 마우스 좌표를 캔버스 좌표로 변환하는 보정을 넣어 클릭 지점과 실제로 칠해지는 위치를 일치시켰습니다.
- **WebGL 메모리 관리** — 프리뷰 지오메트리(평면 · 큐브 · 구체)를 교체할 때 이전 지오메트리의 버퍼를 명시적으로 해제해, 반복 전환 시 메모리가 누적되는 문제를 막았습니다.
- **결과 확인과 내보내기** — Three.js `OrbitControls` 로 회전 · 확대하며 재질을 확인하고, 각 맵을 PNG로 내보냅니다.

### 3. PCG 기반 절차적 배치와 Nanite

가로수, 벤치, 구조물처럼 반복되는 오브젝트를 손으로 배치하는 작업은 Unreal Engine 5의 **PCG 프레임워크로 규칙을 정의해 자동 배치** 하는 방식으로 제작하였습니다.
고해상도 에셋을 프레임 저하 없이 다루기 위해 **Nanite 가상화 지오메트리** 를 적용하고, 조명은 **Lumen** 으로 처리했습니다.

## 💡 회고

**랜덤한 생성형 AI 결과물에 의존하지 않기 위해 노력하였습니다.**
생성형 AI는 결과의 편차가 커서, 파이프라인에 그대로 연결하면 품질이 아니라 운에 의존하게 됩니다. AI에게 의존하지 않고 도구로써 사용하기 위해 특정 기능을 하는 툴을 제작하는 방식으로 작업하였습니다.

**AI를 활용한 다양한 데이터를 다루는 경험을 얻었습니다.**
빠른 작업을 위하여 GIS 벡터 데이터, 건물 높이 DB, 현장 사진, 3D모델, 텍스처맵 등 가능한 많은 데이터를 AI를 이용하여 생성하고, 가공하는 경험을 얻었습니다.
